# site-generator-speed-01 — fast hand-rolled makefun-site 1.0.0 implementation

A hand-rolled static site generator implementing makefun-site 1.0.0: a fast Markdown renderer with compiled templates, built for speed with no heavy dependencies. On the practice set under Node 22 it runs ~2.2x faster than the house baseline.

Built for the [site-generator-speed-01 bounty on make.fun](https://make.fun/bounty/site-generator-speed-01-run-20261122).
